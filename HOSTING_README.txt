REWARD360 PORTABLE WEBSITE

Extract the entire ZIP first. Double-click index.html to preview locally.
Keep every page folder and the assets folder together. Inner pages use relative links to explicit index.html files.
To host: upload all extracted files and folders into your hosting directory. No build step or database is required. Works at a domain root or in a subfolder.
Forms prepare email drafts; a configured email application is needed to send. They do not submit to a backend.
The calculator uses sample values. Some browser features such as clipboard or stored preferences may be restricted for local file previews; HTTPS hosting enables normal browser behavior.
